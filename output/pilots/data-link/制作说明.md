## 这次借鉴什么

不是迁移框架或增加装饰，而是先定义每个节拍的“观众问题、固定对象、关键变化、错误风险”，再写动画。

1. 同一设备 ET-01、加工轮次 RUN-17、晶圆 W03，贯穿整个小样。
2. 过程与配方卡经过核对后靠拢，身份不改写；随后识别来自 RUN-16 的量测并移出。
3. 正确真实膜厚仍为空，镜头聚焦该空缺；模型的示意预测不能填补真实标签栏。
4. 最后提出授权补齐、核对与独立验证，明确是待办，不动画演成已经成功。

[制作前分镜及参考片段](../../../experiments/data-link/storyboard.md)记载 LLManim、Hartquist、Archon 的具体借鉴与不适配部分。没有复制它们的图像、音乐或旁白。所有记录、ID和曲线均为合成示意，实际关联条件比画面复杂。

在项目根目录执行，使用项目现有 Node / Canvas / FFmpeg 依赖和 Noto CJK 字体；本小样没有修改公共课程渲染器或质量门禁。

```sh
npm ci
node experiments/data-link/build.mjs --audio
node experiments/data-link/build.mjs --stills
node experiments/data-link/build.mjs --render
node experiments/data-link/verify.mjs
```

新增旁白位于 `experiments/data-link/narration.json`，动画位于 `experiments/data-link/art.mjs`。配音使用现有 edge-tts 7.2.8、zh-CN-XiaoxiaoNeural、-10%；有效 MP3/SRT 缓存存在时不重复请求。重新生成语音需网络，会向服务发送公开科普文案；未调用付费 API。中间 WAV、静音视频保存在 `tmp/data-link/`，不上传仓库。

## 实际验证

- `verify.mjs`：**24 项检查通过**。包含六节拍连续、字幕完整、最多两行、帧数、音轨、章节、全片解码、音量，以及原五集和质量批次没有改变。
- 2,445 帧完整；音画时长都为 81.500 秒；平均音量 -19.3 dB，峰值 -2 dB。
- 对内容区每帧检查身份和未知量状态；每 0.2 秒检查绘制文字，防止过渡中提前显示“已关联”或“已排除”。共检查 16,322 次文字绘制，无画布越界。状态检查依赖模型化状态，不能单独证明语义正确，另查实际成片帧。
- 24 张最终 MP4 解码帧覆盖每节拍开始、过渡中、过渡后和停留态，文件索引在 `verification.json` 的 `reviewTimes`。已检查错误候选移出与比较缺失值等关键帧。
- 首轮检查发现误差说明挤到真实值卡片边缘，改为比较区域的两行短句后重新导出、检查。
- Chrome 153 以 1 倍速度从起点播放到 ended，8/8 个跳转目标通过，未记录中途 waiting/stalled/error，浏览器丢帧为 0。证据：[browser.json](review/browser.json)。无头播放器解码不代表人工听到了声音。
- 六段最终音轨与源 PCM 相同时间位置相关系数最低约 0.999975，均超过 0.99 检查门槛。本地 Whisper base 无脚本提示转写：233 个汉字、24 个编辑差异，含“膜厚/模后”等同音及其他错误；**约10.3%是ASR误差，不是配音错误率**。证据：[audio.json](review/audio.json)。
- 桌面和844×390横屏截图保存在 `../../playwright/data-link-desktop.png`、`../../playwright/data-link-landscape.png`。小字号记录详情仍建议电脑观看。
