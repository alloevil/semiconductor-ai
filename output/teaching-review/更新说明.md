# 2026-09-28 教学体验更新

本轮是在既有五集内容上做针对性修改，不增加新课程、不改原始旁白文字、不更换配音服务。

## 改了什么

1. **句级主题高亮**：第三至第五集不再按固定时长轮播节点。根据当前语音字幕句子匹配主题；一句涉及多个主题时可以同时高亮。无当前旁白时不保持主题高亮。图形的入场、机械示意等其他动画仍保留原设计，不宣称全片每个动作都已逐字同步。
2. **11 条术语提示**：第二至第四集在副标题区补充光刻胶、CMP、套刻、Fabless、Foundry、EDA、IP 核、IDM、SOP、BOM、配方的简短解释。依据原脚本与已有资料；提示从对应语音句子开始显示，不是词级对齐。
3. **7 道题留出思考时间**：第一集 3 题、第二集 2 题、第三集 2 题，分别在答案前加入 3 秒静音。合计增加 21 秒；原语音采样未删除，题目字幕在静音期间保持可见，答案和后续字幕同步后移。
4. **修复第五集三处图解歧义**：区分设备产品检测与公司内部提效；将设备、时间、批次显示为联合匹配条件而非工序；在评测图中补齐训练、冻结模型、同一留出测试与统一验收。

```sh
npm run check:all
node scripts/check-teaching.mjs --episode=03
node scripts/teaching-evidence.mjs --episode=03
```

`check:all` 已包含全部教学检查。每集 `review/teaching.json` 保存检查项、实际视频 SHA-256 和截图采样时刻。

- **303 项全部通过**：210 项基础检查、9 项第二集工艺检查、9 项第五集图解检查、75 项教学检查。
- 原始旁白：50/50 个合成 MP3 摘要一致，没有新增网络配音请求。
- 停顿：7/7 个答案前增加 3 秒。最终 MP4 解码检查停顿中间 2.7 秒 RMS 小于 0.001；采样点前后均位于原 PCM 零幅度位置，见 `pause-boundaries.json`。
- 显示：停顿中画面保留“想一想”，答案在对应音频开始后才显示；11 条术语均有对应旁白时间且文字不越界。
- 高亮：按相同语音句子检查主题是否激活，并确认起播留白和片尾留白不会继续轮播。该检查不是语义模型，也不证明全部主题匹配都最优。
- 实际画面：各集 `review/teaching-frames/` 为最终 MP4 中术语、主题和问答停顿时刻的解码截图；`frames/final-contact-sheet.jpg` 为当前成片各段总览。

- 播放与跳转：本轮重新打开五个最终 MP4 正常速度播放；结果记录在各集 `review/browser-playback.json`、`review/browser-seek.json` 和 `../series-playback-review.json`，以实际报告为准。
