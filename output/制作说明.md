# 半导体入门 · 第一集

## 观看

- 中文字幕：`episode-01.zh-CN.srt`。视频已烧录字幕，直接打开 MP4 即可；不必再次加载 SRT，以免字幕叠加。

第一集只建立材料、器件、电路与晶圆载体之间的关系。下一集才展开芯片制造工序。本次不是五集全套成片。

本次成片：336.467 秒（约 5 分 36 秒），14,046,939 字节（13.4 MiB）。

## 制作方式

- JavaScript + @napi-rs/canvas 绘制原创矢量式图形，并按确定性时间轴生成画面。
- 1920 × 1080，30 fps，H.264 / yuv420p 视频，AAC 48 kHz 单声道旁白。
- 米白背景、大字概念、颜色分类、逐步出现的结构和关系图。
- 中文旁白由 AI 合成，使用 Microsoft `zh-CN-XiaoxiaoNeural`，`edge-tts==7.2.8`，语速 `-10%`。
- 未使用 OpenAI 付费接口，没有音乐或搬运素材。片内持续披露 AI 合成旁白与非真实比例示意。
- 语音按段缓存；字幕使用服务返回的句级边界，微小重叠已裁齐，不宣称逐字强制对齐。
- 片长按音频实长生成，不为凑整五分钟截断句子。

## 可重复运行

在项目根目录运行：

```sh
npm ci
npm run prepare:audio
npm run preview
npm run render
npm run check
```

环境要求：Node.js ≥ 22、Python / uv、可用的 Noto CJK 字体。当前绘图脚本使用系统中的 `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc` 与 `NotoSansCJK-Bold.ttc`。

`prepare:audio` 使用 uv 调用固定版本 edge-tts。缓存有效时不会重新向服务发送旁白。重新生成语音需网络，且外部语音服务的长期可用性不由本项目保证。语音会发送公开科普脚本，不包含私有业务资料；无需 API 密钥。

FFmpeg / ffprobe 二进制由 npm 依赖提供。渲染和编码不要求浏览器、GPU 或云渲染服务。

## 验证证据

- `render.log`：分段帧数、编码耗时、最终导出日志。
- `verification.json` / `verification.txt`：脚本一致性、字幕覆盖与时间、尺寸、帧率、帧数、音画时长、音量、全片解码与文件摘要。
- `frames/video-*.png`：从最终 MP4 解码提取的各段画面，而非仅检查源图。
- `frames/storyboard.jpg`：源动画的分镜总览。
- `transcribe/speech-check.json` 保存第 01、03、06、10 段的本地机器转写结果。无文本提示的 Whisper base 抽检为 422 个汉字、38 个编辑差异（约 9.0%），包含“晶圆／经缘”等同音转写；不能据此断言配音读错，也不能宣称术语发音经过人工验收。

是否通过，以实际生成的验证报告为准。图形是教学示意，不是工艺仿真；本片也不构成实际设备操作指导。
