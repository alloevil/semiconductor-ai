## 重制

在项目根目录运行，环境要求与前两集相同；没有新增 npm 依赖。

```sh
npm run prepare:audio -- --episode=03
npm run preview -- --episode=03
npm run render -- --episode=03
npm run check -- --episode=03
node scripts/check-text-bounds.mjs --episode=03
```

图形在 `scripts/art-business.mjs`，按集数选择内容。音频和渲染缓存隔离，默认命令仍处理第一集。配音固定为 edge-tts 7.2.8 / zh-CN-XiaoxiaoNeural / -10%；所有实际客户数据均未使用。
