## 制作与重现

项目根目录先 `npm ci`，需要 Node.js ≥22、Python / uv 和 Noto CJK 中文字体，当前字体路径针对 Linux。渲染使用已有 Canvas 和 FFmpeg，无需 GPU 或云服务。

```sh
npm run prepare:audio -- --episode=03
npm run preview -- --episode=03
npm run render -- --episode=03
npm run check -- --episode=03
npm run check:all
```

把 `03` 换成 `01` 至 `05` 即选择对应集数。第一集输出在本目录，其余各集在 `episode-XX/`；分段 MP3、SRT 与缓存索引保留，较大中间 WAV 和模型不提交 Git。

- 第一集图形：`scripts/art.mjs`；第二集：`scripts/art-02.mjs`。
- 第三至第五集：`scripts/art-business.mjs` 中的各集内容与图形；使用多种关系、设备、流程和时序图，不是实际工厂数据。
- 旁白与分镜：`content/episode-01.md` 至 `content/episode-05.md`。
- 来源：`content/references.md`、第二集脚本末尾，以及 `content/series-sources.md`。
- 配音：edge-tts 7.2.8，zh-CN-XiaoxiaoNeural，语速 -10%，片内披露为 AI 合成；不调用 OpenAI 付费接口。

本地语音复核可运行：

```sh
uv run --with faster-whisper==1.2.1 --with opencc-python-reimplemented==0.1.7 python scripts/review-audio.py 03 04 05
```

首次下载公开 Whisper base 模型需要网络。该命令从最终视频提取音轨，与源 PCM 做同位置波形比较，再逐段转写。识别误差不能当成配音发音错误率，也不能替代人工试听。

## 仍然保留的限制

科普试播版，不是工艺操作指南、投资建议或已验证的 AI 落地方案。第四集为典型工程生命周期归纳，不是某公司的内部 SOP。第五集明确区分厂商公开能力与课程建议，图中曲线、异常和评测是教学示意，没有真实客户信息。

没有人工逐句听完整套旁白，未做全套行业专家审校；无头浏览器播放和机器转写不能冒充人耳验收。仅验证本机 Chrome，不代表所有浏览器和手机硬件均兼容。

配音服务的公开传播与商用条款尚未核实；免密钥不等于任意授权。仓库也未指定开源许可证，公开可见不代表授予任意复制、修改、分发或商业使用权利。
