# 第一集成片复验

> 此报告属于教学优化前的首发版本，保留用于追溯。新版证据见 `../teaching-review/更新说明.md` 与各集当前验证报告。

验证日期：2026-09-27。

## 结论

**技术交付通过，可以观看。** 本轮没有发现需要重制视频的文件损坏、解码失败、字幕越界、整体音轨错位或明显概念关系错误。未进行人工逐句试听，不把自动转写当作发音验收。

验证对象：`../episode-01.mp4`。

SHA-256：`2ebb945dcb5ddb6e6bed779a10e767620afd36ccb0bceabd6cafb35b1f7259b4`。

本轮没有修改成片或动画源代码，仅刷新验证产物、补充报告和说明。

## 1. 自动验收复跑

命令：项目根目录执行 `npm run check`。

- 42 项检查全部 PASS。
- 1920 × 1080，30 fps，H.264 / yuv420p，AAC 48 kHz。
- 时长 336.467 秒，10,094 帧，11 个嵌入章节。
- FFmpeg 全片解码通过，无错误。
- 57 条字幕完整覆盖原稿，时间不重叠，最多两行。
- 音画轨道时长差约 34 毫秒。仅凭这一指标不能证明语义同步，因此另做音频时间位置检查。
- 平均音量 -18.7 dB，峰值 -2.0 dB；非静音，无满幅削波。

证据：`../verification.json`、`../verification.txt`。

## 2. 真正播放整片

通过 Playwright CLI 驱动本机 Linux Chrome 153，直接打开最终 MP4，以 1 倍速度从 0 播放到结束；音量为 1、未设置静音。无头浏览器音轨解码正常不等于人工听到了声音。

- 正常触发 `ended`，结束位置 336.467 秒。
- 每秒采样一次，共 336 次，所有采样 `readyState=4`、`paused=false`。
- 除起播时刻的 `waiting` 外，没有中途 `waiting`、`stalled` 或媒体错误事件。
- 浏览器累计记录 1 帧丢帧；未要求“零丢帧”，也未将它隐去。浏览器总帧计数包含审查开始前的自动播放，应以 FFprobe 的 10,094 帧判断文件帧数。
- 音频解码字节计数持续增加，结束时为 6,310,273 字节。

证据：`browser-playback.json`、`../playwright/normal-playback.png`、`../playwright/playback-ended.png`。

## 3. 跳转与视口

最初使用 Python 临时 HTTP 服务测试，12 个跳转实际都返回 0 秒。该服务不支持所需的视频范围请求，**这次测试是 FAIL，不能因为触发 seeked 就当作成功**。

将同一份完整 MP4 载入浏览器 Blob，消除 HTTP 范围请求的影响后复测：

- 12/12 个位置跳转成功，包括十个场景附近、片尾和回跳。
- 目标与实际位置一致；各次耗时 10–76 毫秒，媒体错误均为空。
- 证明文件可寻址，不代表 Python 临时服务器适合发布视频；未来如果网页托管，需要支持 HTTP Range 的服务器。

截图检查：1440 × 900 桌面视口及 844 × 390 横屏视口。未裁掉主内容，播放状态下字幕可见。暂停时播放器原生控制条会临时覆盖底部字幕，播放后控制条隐藏，不能混淆为视频本身烧录了遮挡。

证据：`browser-seek.json`、`../playwright/desktop-1440x900.png`、`../playwright/landscape-844x390.png`、`../playwright/landscape-playing.png`。

## 4. 实际视频画面抽查

新增抽取十段各 8%、45%、90% 时刻，共 30 张实际 MP4 解码帧，逐张通过五张总览检查；不是仅检查绘图源文件。

- 未发现标题或字幕溢出、主要标签重叠。
- 空白晶圆与加工后晶圆有明确区别；晶体管图没有机械闸门；裸片与封装示意有区分。
- 关系图明确区分材料、器件、电路和载体，没有将其画成一条完整生产流程。
- 复习题与后续预告正常出现。

证据：`contact-1.jpg` 至 `contact-5.jpg`，以及对应单帧 PNG。

## 5. 最终音轨检查

从最终 MP4 解码为 16 kHz 单声道 PCM，再与归一化源旁白在相同采样位置逐段比较。

- 10/10 段零位移波形相关系数超过 0.99998（检查门槛 0.99）。
- 没有发现 AAC 合成引入的整体时间错位、换段或缺失。
- 这项检查验证的是成片相对于源音轨的时间一致性，不证明句级字幕边界毫秒级准确。

另用本地 Whisper base 对最终音轨十段全部转写，未提供原文提示；繁简归一化后，与原稿比较得到 1,096 字、68 个编辑差异，字符错误率约 6.2%。

转写内容覆盖各段主题，差异含“晶圆／经缘”“硅／归”“封装／风装”等同音替换，也有非同音差异。因此**不将 6.2% 写成配音错误率，也不宣称所有术语已经发音正确验收**。

证据：`audio-alignment.json`、`final-audio-transcription.json`。

## 残余限制与观感建议

- 手机横屏下主标题、主体概念与字幕可以阅读，但辅助说明较小；建议横屏全屏或电脑观看。没有制作竖屏适配版。
- 本片属于信息图教学动画，部分画面保持较长时间供理解，不是写实三维纪录片。这不是文件故障，本轮不擅自改变视觉方案。
- 未进行人工完整听感评审；机器转写不替代发音、语气和节奏的人工判断。
- 只实测本机 Chrome；未测试 Safari、微信、电视和不同手机的硬件解码。
