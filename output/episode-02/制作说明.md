## 重制

从项目根目录运行；依赖、系统字体和 uv 要求与第一集相同，无新增 npm 依赖：

```sh
npm ci
npm run prepare:audio -- --episode=02
npm run preview -- --episode=02
npm run render -- --episode=02
npm run check -- --episode=02
node scripts/check-process.mjs --episode=02
```

动画文件：`../../scripts/art-02.mjs`。音频缓存在本目录的 `speech/`，渲染缓存在项目的 `tmp/episode-02/`。默认不带集数参数仍处理第一集；第一集 MP4 未修改。

语音：`edge-tts==7.2.8` / `zh-CN-XiaoxiaoNeural` / 语速 `-10%`。没有调用 OpenAI 付费接口。公开科普脚本会发送到语音服务，重新生成时需要网络。配音服务的传播与商用条款尚待核实，不宣称免密钥等于有任意授权。
