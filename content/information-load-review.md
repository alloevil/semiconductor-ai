# 全套文字层级审查：定位后定点减负

## 方法与范围

对五集50段各取22%、50%、65%、90%四个时刻，共200个源绘图样本，记录文字、字体（含缩放）、纵向区域和渲染字符数。结果见 output/information-load/before/audit-*.json。

区域按纵坐标启发式划分，字幕和图内文字也可能分到相邻区域；不能把字符数、字号或重复文字直接当“认知负荷分数”。使用实际成片画面确认问题，仍未取得真人理解与阅读反馈。

## 五集处理结论

| 集数 | 检查重点 | 本轮处理 |
| --- | --- | --- |
| 01 | 材料、器件、载体说明与复习题是否需要同屏 | 保留。定义、关系图、题目字幕承担不同任务；不凭重复术语删去定义。 |
| 02 | 显影/刻蚀相邻概念的标题、限定与总结 | 保留。强调目标膜仍存在有防误解作用，当前未发现需要删除的遮挡。 |
| 03 | EDA/IP、IDM解释与协作图 | 保留术语提示；它们补充新手所需含义，不等于装饰副标题。 |
| 04 | 配方、部件版本、待验证状态 | 保留版本和“待调试验证”。不能为了减字让装配看起来已经验收。 |
| 05 | 知识助手、联合数据键、模型评测的并行文字 | 仅修改02段知识助手，其他内容先保留。数据关联图字多，但各字段与客户边界不能按字数直接删除。 |

## 选择第五集02段的依据

65%时刻同屏25次文字绘制、321个字符；旧手册缩放为0.52后，说明文字约11.44px、Doc-A/R1约16.12px（1080p画布坐标）。

重复层包括：副标题“流畅，不等于正确；版本和权限不能省略”、右侧证据不足及安全提示、底部“证据不足就说明，不编造维修步骤”和正在读出的字幕。主体已经完整表达这些信息。

## 最小修改

1. 原知识助手标题保留，下方直接放同一问题与身份，不再叠加泛化副标题。
2. 底部总结条移除，但保留右侧“证据不足”“不编造步骤、不下指令”与“工程师确认/安全规程/权限”，原字幕也不动。
3. 主体左右面板从445px高增加至610px高，利用释放的上下空间；不横向挤压或拉伸图形。
4. 被排除的旧文档仍保留完整ID和状态，最小缩放提高到0.72；“合成手册示例”不消失。
5. 动作锚点、版本筛选顺序和未知根因状态不变。不新增其他知识、不改音轨。

## 验收规则

- 在同一语音时刻对照，不使用不同截图来制造差异。
- 要求屏幕上的证据缺口、候选状态、旧版排除、权限安全边界仍存在；字幕与原稿字节一致。
- 全段过渡中记录不互相遮挡；关键文档ID最小有效字号提高，而非仅把背景画大。
- 其他49段同时间点像素一致、第一至第四集视频摘要不变、第五集AAC包及字幕字节不变。
- 正常播放、跳转、桌面/横屏及全套机器检查后才发布；质量门禁保持阻断。
- 只报告布局测量与机器证据，不宣称因此理解率提高。
