## O1.1 · 区分材料、器件、电路、晶圆载体，并解释它们的关系。

讲解位置：[第 1 集脚本](../content/episode-01.md)，场景 02（00:29 半导体首先是一类材料）；03（01:02 从材料到器件：晶体管）；05（02:07 芯片不是一只巨大的晶体管）；06（02:39 晶圆是加工的载体）；09（04:17 把概念放回一张图）。时间来自当前实际时间轴，精确值以 JSON 为准。

**A 卷：**把硅、晶体管、集成电路、晶圆分别归到材料、器件、电路、加工载体。再用一句话说明这些对象怎样联系起来。

**B 卷：**有人说：晶圆、晶体管和芯片只是同一样东西的不同叫法。请用硅、晶圆、晶体管和集成电路四个词纠正这句话，并说明它们怎样联系。

**评分点（各 1 分）：**

1. 硅归为半导体材料
2. 晶体管归为器件
3. 集成电路归为器件和连接组成的电路
4. 晶圆归为制造过程中的加工载体
5. 说明在晶圆上加工器件及连接形成电路；不是逐个粘上现成晶体管【关键点】

**误解观察：**把晶圆、晶体管和集成电路当成同一层级同义词。 不得分并不自动意味着明确误解；请记录参与者原话。

## O1.2 · 区分加工晶圆、裸片与封装，并认识芯片用途不只计算。

讲解位置：[第 1 集脚本](../content/episode-01.md)，场景 05（02:07 芯片不是一只巨大的晶体管）；07（03:10 从晶圆到裸片，再到产品）；08（03:42 芯片不只有处理器）。时间来自当前实际时间轴，精确值以 JSON 为准。

**A 卷：**电路板上有一个黑色器件，拆开后看到两块裸片。解释黑色器件、裸片、加工后的晶圆三者的关系，并举出计算之外的两种芯片任务。

**B 卷：**一片已经加工的晶圆经过后续加工成为电路板上的封装器件。说明晶圆、分割得到的裸片、外部封装分别是什么，封装里是否一定只有一块裸片？再举出两种非计算任务。

**评分点（各 1 分）：**

1. 加工晶圆通常有多个电路区域，尚不等于单个封装产品
2. 裸片是分割取得的一小块芯片实体
3. 封装承担保护和连接等功能，不等于内部裸片【关键点】
4. 一个封装可以包含多块裸片
5. 举出两种合理非计算用途，如存储、信号处理、电源管理（只列一种不给此分）

**误解观察：**外部封装等于裸片，或所有芯片都是处理器。 不得分并不自动意味着明确误解；请记录参与者原话。

## O2.1 · 在正性光刻胶的简化例子中区分曝光、显影、刻蚀分别改变哪层。

讲解位置：[第 2 集脚本](../content/episode-02.md)，场景 03（01:11 光刻：先把图案交给光刻胶）；04（01:44 显影：图案变成开口）；05（02:18 刻蚀：把图案转移到目标材料）。时间来自当前实际时间轴，精确值以 JSON 为准。

**A 卷：**有衬底、绿色目标薄膜、橙色正性光刻胶三层。刚曝光但尚未显影时，哪些层仍存在？随后显影和刻蚀分别移除什么？这个例子能代表所有工艺吗？

**B 卷：**一段动画用光照过后就直接让目标膜出现沟槽，省去了其他步骤。请按本课的正性光刻胶例子说明哪里有误，以及曝光、显影、刻蚀三个阶段分别应画出什么。是否所有工艺都这样？

**评分点（各 1 分）：**

1. 曝光主要改变光刻胶性质
2. 曝光后光刻胶和目标膜仍存在，不直接刻掉目标膜【关键点】
3. 显影选择性去除曝光区域的胶形成开口
4. 刻蚀通过开口移除目标材料，保护区域应保留
5. 限定为所选正性胶和简化刻蚀例子，不泛化到所有工艺

**误解观察：**曝光本身直接把硅或目标膜雕成沟槽。 不得分并不自动意味着明确误解；请记录参与者原话。

## O2.2 · 解释反复加工、清洗和量测为什么不能由一次设备正常运行替代。

讲解位置：[第 2 集脚本](../content/episode-02.md)，场景 02（00:34 沉积：先增加一层材料）；06（02:52 去胶与清洗：为下一步准备表面）；08（04:03 量测与检测：机器没报警，还不够）；09（04:39 重复加工，再走向封装测试）。时间来自当前实际时间轴，精确值以 JSON 为准。

**A 卷：**操作记录说沉积设备全程没有报警，因此本批晶圆一定合格，而且只需在所有加工结束后清洗一次。指出两个结论的问题，并说明应检查哪些结果。一轮加膜、图案形成与去材料能否代表整个芯片已经完成？

**B 卷：**一块晶圆完成一轮加膜、做图案和去材料后，工程师想直接当成最终合格产品交付。为什么信息不足？清洗、重复加工和量测分别还起什么作用？

**评分点（各 1 分）：**

1. 设备无报警或单轮执行成功不等于产品合格【关键点】
2. 要量测厚度、尺寸、套刻或其他与任务相符的结果
3. 要将量测或检测结果与要求比较，而非只得到数值
4. 清洗穿插工序以去除残留和污染，并非只在最后
5. 完整芯片通常需要反复加工，多轮材料和图案可能不同

**误解观察：**机器无报警即可认定晶圆合格。 不得分并不自动意味着明确误解；请记录参与者原话。

## O3.1 · 根据交付对象识别设计、代工、封测、设备及材料角色。

**A 卷：**甲交付电路设计，乙为客户加工晶圆，丙提供刻蚀机，丁负责裸片封装测试，戊提供光刻胶。分别判断五者角色，并指出谁是使用刻蚀机加工晶圆的一方。

**B 卷：**一个项目分别采购电路设计服务、晶圆制造服务、封装测试服务、沉积机和工艺气体。写出对应的五类供应方，并说明为什么卖沉积机的一方不自动等于替客户制造芯片的一方。

4. 正确区分设备提供方与设备使用方（两者均需说清）【关键点】
5. 正确识别工艺材料供应角色

**误解观察：**设备制造商与使用设备的晶圆厂是同一角色。 不得分并不自动意味着明确误解；请记录参与者原话。

## O3.2 · 解释企业角色可交叉，以及设计工具或 IP 不能取消制造约束和验证。

讲解位置：[第 3 集脚本](../content/episode-03.md)，场景 02（00:34 设计公司决定芯片做什么）；03（01:09 晶圆厂把设计变成物理结构）；07（03:36 设计工具与可复用模块）；08（04:12 一家公司可以承担多个角色）。时间来自当前实际时间轴，精确值以 JSON 为准。

**A 卷：**一家企业自己设计并制造部分芯片，也把另一些产品交给外部代工。它还能被理解为 IDM 吗？另一家只有设计业务，采用 IP 核和 EDA 后是否可以不管工艺规则与验证？解释理由。

**B 卷：**有人认为：企业只能在设计公司、代工厂、IDM 中永久选一个标签；现成 IP 加自动化设计工具可以保证制造成功。请分别纠正这两种说法，并解释工具、模块和制造规则的关系。

**评分点（各 1 分）：**

1. IDM 表示同时具有设计与制造能力，不要求所有产品都自制
2. 企业业务可交叉，外部合作不自动取消内部制造能力
3. EDA 是辅助设计、验证和实现的工具，不是制造成功保证
4. IP 是可复用设计模块，不等于无需系统验证【关键点】
5. 设计及模块需匹配工艺规则和接口等约束

**误解观察：**复用 IP 或使用 EDA 后不需要验证和制造约束。 不得分并不自动意味着明确误解；请记录参与者原话。

## O4.1 · 区分设备出厂、现场应用与维护后的验证责任。

讲解位置：[第 4 集脚本](../content/episode-04.md)，场景 01（00:00 制造机器，不是制造晶圆）；02（00:35 客户买的是结果，不只是机器）；05（02:25 调试与验证不是通电就结束）；06（03:01 客户现场需要安装和应用配合）；08（04:15 维护是持续服务，不只是救火）。时间来自当前实际时间轴，精确值以 JSON 为准。

**A 卷：**一台沉积设备出厂测试通过，运到客户现场后膜厚异常。供应方说出厂已通过，所以现场无需验证；维修后能通电就可恢复生产。说明两个工厂的制造对象、这两项判断的问题，并指出谁应参与确认。

**B 卷：**设备在供应商工厂能正常运行，客户安装后也能启动，但还没有加工结果记录。两个工厂分别制造什么？是否足以确认现场交付完成？若之后换过关键部件，还应确认什么？哪些团队需要协作？

**评分点（各 1 分）：**

1. 设备商装配机器与客户加工晶圆是不同现场和对象
2. 出厂测试不覆盖所有现场环境、安装和应用条件
3. 启动或通电不等于目标加工结果达标
4. 维护或换件后需要验证状态及加工表现，不能自动恢复生产【关键点】
5. 至少指出客户与设备服务/应用/工艺团队协作，责任依约定（不能只答 AI 决定）

**误解观察：**出厂通过或维修后能通电，就可跳过现场加工验证。 不得分并不自动意味着明确误解；请记录参与者原话。

## O4.2 · 提出能追溯设备异常的数据清单，区分候选原因和已验证根因。

**误解观察：**看到相关信号就确定根因，或设备商可无条件获取客户数据。 不得分并不自动意味着明确误解；请记录参与者原话。

## O5.1 · 依据任务与数据条件选择合理 AI 范围，承认预测与诊断限制。

讲解位置：[第 5 集脚本](../content/episode-05.md)，场景 02（00:36 第一条线：工程师知识助手）；03（01:12 第二条线：异常检测与排障辅助）；04（01:51 第三条线：维护时机与健康状态）；05（02:29 第四条线：配方优化与虚拟量测）；07（03:44 数据能否形成闭环）。时间来自当前实际时间轴，精确值以 JSON 为准。

**A 卷：**团队有报警和传感曲线，但没有可靠膜厚量测标签，也没有完整失效记录。有人承诺立即预测膜厚和部件准确剩余寿命。指出限制、可先做的任务、需要补的数据，以及结果应怎样交给工程师。

**B 卷：**模型能检索维修手册，并发现温度与压力同时异常。负责人据此说它已经能确定根因、取消真实量测和保证维护收益。你如何纠正？下一步先做什么、补什么数据？

**评分点（各 1 分）：**

1. 虚拟量测或膜厚预测需要可信真实量测训练/验证，不能无依据取消量测【关键点】
2. 寿命或维护收益判断受失效/维修记录及工况质量限制，不能保证准确寿命
3. 提出可先做的有限任务：带来源检索、异常提示或健康评估等
4. 需要设备/时间/批次关联，并在客户授权范围内补足量测或维修标签
5. 输出证据、候选与不确定性并由工程师验证，不把相关性当根因

**误解观察：**没有真实标签和验证也可保证量测预测、根因或维护收益。 不得分并不自动意味着明确误解；请记录参与者原话。

## O5.2 · 设计控制变量的评测与受控上线步骤，避免数据泄漏和不安全执行。

讲解位置：[第 5 集脚本](../content/episode-05.md)，场景 08（04:24 用同一把尺子比较）；09（05:01 先建议，再验证，最后受控使用）；10（05:38 五集之后，你该会问什么）。时间来自当前实际时间轴，精确值以 JSON 为准。

**A 卷：**团队不断看测试集结果调参，只拿 AI 与人工处理不同样本的结果比较，演示成功后计划让模型直接改设备参数。请给出公平评测和上线步骤，指出不可绕过的边界。

**B 卷：**给一个设备排障助手设计验收：现有规则与 AI 如何公平比较？测试数据如何与开发区分？什么指标不能只靠准确率？从离线到现场执行前应经过哪些限制和审批？

**评分点（各 1 分）：**

1. 同一任务、同一测试样本与同一评分口径比较规则/人工/AI
2. 按时间或设备留出测试，开发调参与最终测试分开，避免泄漏
3. 包含误报漏报代价、处理时间或人工复核负担，而非只报准确率
4. 先离线验证再只读现场观察，经过验证与批准才有限受控使用
5. 安全联锁、客户权限、人工审批不可绕过，并保留日志或回退/变更后验证【关键点】

**误解观察：**一次演示成功就可跳过审批和安全联锁，让 AI 直接改设备。 不得分并不自动意味着明确误解；请记录参与者原话。
