# 内容与教学质量验收

**当前状态：技术交付已验证；内容正式验收与学习者试学尚未完成。** 本目录提供可执行的审查材料，不表示获得认证或保证学习效果。

## 先用哪些文件

1. [目标与题目映射、评分表](rubric.md)：10 个学习目标，各 5 个评分点；每集 10 分，全套 50 分。
2. 学员只领取 [A 卷](learner-A.md) 或 [B 卷](learner-B.md)，不要提前阅读评分答案。公开仓库无法防止答案泄漏，试学前必须询问是否已看过答案。
3. [关键主张台账](claims.md)：25 条，不是逐句穷尽。来源支持范围、图示简化和待复核项逐条列明。
4. [独立复核与发布清单](review-checklist.md)：哪些问题会阻断正式课程发布，谁来检查，如何留证。
5. [真实学员试学协议](pilot-protocol.md)：招募、前后测、评分、误解记录、阈值与隐私处理。
6. [当前证据与门禁状态](status.json)：所有未完成的人工作业保持 pending，不自动放行。

## 采用的方法与实际适配

### CMU：目标、教学和考核对齐

2026-09-28 已读取 [Eberly Center 指导](https://www.cmu.edu/teaching/assessment/basics/alignment.html)。它区分回忆、解释、应用和分析等目标，强调考核必须检验所教能力。

- 适配：从“听过术语”升级为分类、解释原因和新情境判断；每道题映射目标、对应片段与评分点。
- 不适配：照搬大学课程难度，要求零基础观众计算实际工艺参数。本题库没有这些要求。
- 边界：两套题为本项目原创设计，难度尚未经实测校准；不是 CMU 认证题库。

### W3C：音频、字幕与关键视觉信息的等价

2026-09-28 已读取 [字幕](https://www.w3.org/WAI/media/av/captions/)、[视觉描述](https://www.w3.org/WAI/media/av/description/)及[描述性文本](https://www.w3.org/WAI/media/av/transcripts/)指导。

- 适配：正常观看、只听、静音看三遍检查；核对否定词和限定语；重要箭头含义、图中文字不能只依赖颜色。
- 字幕来自原稿不等于合成语音逐句正确。机器转写、文件相同、波形相近都不能替代人耳核对。
- 现有脚本和分镜可以作为描述性文本的基础，但必须校对与最终画面一致，不能直接标为完整音频描述。
- 不直接宣布符合 WCAG A/AA；还需按实际发布形式、播放器和内容确认要求及证据。

### 本项目增加的编辑与发布方法

主张—来源—边界台账、独立复核签字和证据版本绑定是项目的质量流程，不冒充上述机构的原版制度。5–8 人试学和评分阈值也是预先规定的工程决策，不是教育研究结论。

## 三个等级，不能互相替代

| 等级 | 必需证据 | 当前状态 |
| --- | --- | --- |
| 技术合格 | 当前视频摘要与完整机器检查报告匹配 | 已有报告，检查时重新核验摘要 |
| 内容可正式发布 | 独立内容审校、完整人工试听、信息等价复核、权利核实、开放问题结案 | BLOCKED：尚缺人工作业证据 |
| 学习目标在试学中初步达成 | 真实学员测试和评分记录，满足预注册规则 | BLOCKED：尚无学员数据 |

第三等级仅表示该样本、该条件下的初步结果；不等于广泛或长期“教学有效”。已发布试播文件不会被脚本删除，门禁阻止的是把它升级标注为正式审校课程或验证过的教学成果。

## 命令与材料维护

```sh
npm run quality:materials
npm run quality:check
npm run quality:gate
```

- `quality:materials` 从 `assessment.json`、`claims.json` 和当前时间轴生成两份学员卷、评分表、主张台账。学员卷不附答案，评分表包含答案要点。
- `quality:check` 检查材料关系、当前视频/脚本/代码/题目版本及机器证据，输出 `status.json`。退出 0 只表示材料结构与版本可用，**不是内容质量通过**。
- `quality:gate` 使用同一检查，但任何正式内容发布门禁 pending、blocked 或证据失效就退出 1；这是预期阻断，不应为了“全绿”删除检查或填假批准。
- `release.json` 固定本次审查的文件 SHA-256。改片、改脚本、改题目或评分标准后，旧批准失效；应重新建审查批次，明确变更和需要重做的工作，不可一键覆盖摘要假装审批仍有效。

## 不可由代理代办的证明

代理可以整理资料、运行检查、发现矛盾、编制试卷；不能伪造专家身份、人的试听体验、服务商许可或真实学习者结果。缺这些证据时如实阻断，不推断“应该没问题”。

所有参与者结果在本地私有目录 `quality/private/` 保存且被 Git 忽略。需要公开时仅发布经同意的去标识汇总，不上传姓名、联系方式、录音或未获同意的原始回答。
