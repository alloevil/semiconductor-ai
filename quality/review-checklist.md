## 五道正式内容门禁

### G1 独立内容复核

负责人：没有编写该片的工艺/设备/应用工程或相关专业审查者。记录其适用经验，不编造资质。

- 逐条检查 `claims.md` 的关键主张，同时完整浏览每集查找遗漏主张；发现遗漏要补台账，不因已有 25 条而停止。
- 对事实核对原始来源、适用产品和日期；对工程归纳与建议检查是否标明性质。
- 确认图示没有改变主张：例如曝光不去膜、正性胶不是所有流程、候选不是根因、企业模式不互斥。
- 关键错误、无依据的收益承诺、来源与旁白矛盾、会鼓励绕过安全/权限的表述均为阻断项，必须修正后复核。
- 签字范围要覆盖五集、25 条主张及所有新增项；只签“整体不错”无效。

### G2 人工完整试听与字幕校对

- 正常速度逐句听完五集；逐段记录起止时间、问题与修复结论，不只听样片。
- 重点核对：晶圆、晶体管、裸片、刻蚀、显影、套刻、掺杂、EDA/IP/IDM/BOM、否定词与“可能/通常/本例”。
- 字幕与实际声音含义一致；只核对脚本和字幕文件相同不算试听。
- 检查停顿是否截断、答案是否提前出现、术语解释是否留够阅读时间；不以无头浏览器开启音轨代替人耳。

### G3 关键信息等价复核

- 正常观看：语音、字幕、箭头、颜色和图注是否一致。
- 只听：有没有只有视觉才传达的关键关系；如有，记录需补说明的具体时间点。
- 静音看：字幕是否传达必要音频信息，图注是否清楚标记示意。
- 补充说明的方式由复核结果决定，可采用旁白内整合说明或经校对的描述性文本；不为了省事宣称全面 WCAG 合规。

### G4 权利与使用范围核实

- 明确用途：公开传播、再分发、修改、商业课程或广告；逐项确认音轨服务条款/许可依据及生效日期。
- 记录权利人的正式条款链接和必要许可，审查者明确哪些用途可用、哪些仍不可用。
- 代码、字体、第三方依赖与内容素材的许可分别处理；不能给没有权利的素材套上项目许可证。
- 必要时替换音轨/素材，重新跑技术和听感验收。

### G5 开放问题结案

- F01–F06 中与内容级有关的 F02–F05，以及审查新增问题，必须逐项处理并有依据。
- F01/F06 的学员试验不因内容级通过就自动完成，留到教学级门禁。
- 严重问题不允许用平均评分抵消；建议分为阻断/重要/次要，未处理的重要问题须说明为何不影响当前范围并由独立复核者签字。

## 证据文件格式

每道门禁需要独立的 JSON 证据文件，放 `quality/evidence/`。仅当确实完成后创建；不预填签字。至少包含：

```json
{
  "gateId": "independent_content",
  "releaseFingerprint": "由 quality:check 输出的当前批次指纹",
  "reviewer": "审查者公开同意的标识",
  "role": "真实的相关经验与本次复核角色",
  "reviewerKind": "human",
  "independent": true,
  "reviewedAt": "实际完成日期",
  "decision": "approved",
  "coverage": ["01", "02", "03", "04", "05"],
  "checks": ["completed 的真实检查要点"],
  "claimIds": ["内容门禁需覆盖全部主张 ID"],
  "findings": [],
  "evidenceFiles": [{"path": "quality/evidence/实际复核记录.md", "sha256": "文件摘要"}]
}
```

上面是格式说明，不是可提交的批准材料。其他门禁同样需要真实记录；`rights` 证据还应说明用途与来源；学员门禁按试学协议增加去标识结果汇总。审核人声明不能由脚本鉴定真伪，仍需要负责人检查来源与身份。

改视频、题库或其他被锁定材料会使 releaseFingerprint 变化；不要改 JSON 绕过重新审查。
