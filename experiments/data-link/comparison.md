# 小样观察与对照规则

这是独立演示，不是已经证明优于旧版的替代课程。

## 可观察的目标

不看答案，让观众解释：

1. 两条记录要关联，除了时间接近，还需要核对哪些上下文？
2. ET-01、W03相同，但加工轮次分别为RUN-16和RUN-17，能否直接拼接？为什么？
3. 过程与配方正确关联后，真实膜厚缺失，模型给出预测能否证明准确？缺少哪项证据？
4. 在授权范围内下一步可以做什么？当前有哪些有限任务仍可做？

评分参考：说明加工/晶圆身份、拒绝错轮次、认识真实量测缺失、提出补齐与独立验证并保留有限提示范围。每题1分，记录原话而不是只问“好不好看”。评分只服务该小样，不改变现有质量题库。

## 不能怎样比较

- 本小样把原第五集的知识点具体化为新的短旁白，并非原版音轨重画。因此旧版与小样时长、措辞、示例不同，不能把分数差异仅归因于动画。
- 若做形式比较，须另做相同旁白、相同时长、同评分的静态/动态两版，随机分配初次观看者，保留样本限制。
- 同一人先看旧版再看新版会发生学习效应；不能将二次回答进步直接算作新动画收益。
- 原 quality/ 的门禁不因本小样完成而放行；小样也需要独立审校、实际人耳试听、权利核实和真实试学。
